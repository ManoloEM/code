## About this repository

This repository serves as a structured archive of all academic code produced throughout university studies. Each folder corresponds to an academic stage or specialization.

The repository contains:

| Folder | Content | Period |
|--------|---------|--------|
| [`01_grado_matematicas/`](https://github.com/ManoloEM/code/tree/main/01_Grado_Matematicas/) | Mathematics, algorithms, and an introduction to ML | UMA degree |
| [`02_erasmus/`](https://github.com/ManoloEM/code/tree/main/02_Erasmus/) | Projects developed during the exchange program in Coimbra | Erasmus |
| [`03_computacion_cuantica/`](https://github.com/ManoloEM/code/tree/main/03_Computacion_Cuantica/) | Quantum circuits, algorithms, and simulation | Quant·UMA specialization course |
| [`04_master_mulcia/`](https://github.com/ManoloEM/code/tree/main/04_Master_MULCIA/) | Neural networks, XAI, adversarial ML, RL, expert systems | MULCIA Master's in Seville |
